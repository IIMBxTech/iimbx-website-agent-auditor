- **Brand Colors**:

  - Brand Yellow: `#FDB913`
  - Charcoal: `#333333`

**Workflow:**
- Always default to lazy, minimal solutions (Ponytail mode active), but ALWAYS maintain the TOP LEVEL OF SECURITY (never hardcode secrets, API keys, etc.).
- Never recreate the `variants` directory from scratch unless instructed.
- All development focuses on refining the `design_dashboard.html` and the Krishtech HTML variants inside the `variants/` folder.
